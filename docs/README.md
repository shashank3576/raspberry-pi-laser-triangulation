# Project Documentation

This directory contains the supporting documents for the Raspberry Pi laser triangulation height-measurement project. The photos and design references are kept in [`../images/laser_spot/`](../images/laser_spot/) and are introduced in the [main README](../README.md).

## Project report

See the project report in [report/](report/). It describes the measurement setup, calibration procedure, model, results, and limitations.

## Project presentation

See the project presentation in [presentation/](presentation/) for a concise overview of the system and its results.

## Technical overview

See [TECHNICAL_OVERVIEW.md](TECHNICAL_OVERVIEW.md) for the image-processing stages, calibration-model form, uncertainty calculation, data flow, and reproducibility checklist.

## Repository guide

- Start with the [main README](../README.md) for the project overview, setup instructions, run commands, calibration results, and embedded visual guide.
- Project visuals: physical setup photo, laser-dot examples, triangulation geometry, and 3D design are stored in `../images/laser_spot/`.
- Calibration inputs and the saved model are stored in `../data/calibration/`.
- Generated plots and analysis tables are stored in `../results/`.

The report and presentation are retained as supporting project documents; this index does not replace them.
